# Playbook: content/thread

plan takeaway → 5–7 sourced facts → draft hook-first → review for unsupported claims → ship or loop.

## Steps

1. **Planner** — state the takeaway in one sentence and define the thread's done-criteria (hook, takeaway supported by at least 3 sourced facts, single CTA if any).
2. **Researcher** — find 5–7 sourced facts relevant to the takeaway; tag confidence; flag anything unverifiable.
3. **Builder** — draft the thread hook-first: line 1 earns the read, the body delivers the takeaway through the sourced facts, no unsupported claims.
4. **Reviewer** — check every claim against the research findings; blocker for any unsupported claim; verdict SHIP / FIX THEN SHIP / REDO.
5. **Router** — ship on SHIP; loop back to builder on FIX THEN SHIP (max 2); on REDO return to planner with findings; capture one learning line.
